## Original Assignment

This repository contains the practical assignments completed for the Data Warehousing and Big Data Analytics (DWBDA) subject.

The assignments cover data processing, analysis, visualization, machine learning, and big data technologies using Python and PySpark.

## Assignments Included

### 1. Spark Sales Data Analysis

This assignment uses Apache Spark to process and analyze sales data from a CSV file.

**Topics covered:**
- Creating a Spark session.
- Reading CSV files using PySpark.
- Creating temporary SQL views.
- Using SQL queries for data analysis.
- Calculating total products sold by category.

### 2. Wine Quality Analysis Using PCA and K-Means

This assignment uses the Wine Quality dataset from the UCI Machine Learning Repository to perform multivariate analysis and clustering.

**Topics covered:**
- Loading datasets using Pandas.
- Checking missing values.
- Feature selection.
- Data standardization using StandardScaler.
- Dimensionality reduction using PCA.
- K-Means clustering with three clusters.
- Visualizing clusters using Matplotlib.

### 3. Student Examination Results Analysis

This assignment analyzes students' examination marks using Python and Pandas.

**Topics covered:**
- Calculating average marks.
- Assigning grades based on student performance.
- Counting students in each grade.
- Calculating subject-wise average marks.
- Analyzing examination results.

### 4. Spark Structured Streaming Assignment

This assignment implements a real-time-style data processing pipeline using PySpark Structured Streaming.

It simulates Teesta River water-level readings from five monitoring stations:

- Chungthang
- Dikchu
- Singtam
- Rangpo
- Majitar

**Topics covered:**
- Generating simulated sensor data.
- Reading JSON files as streaming input.
- Handling malformed records.
- Removing duplicate records.
- Using watermarks for streaming data.
- Five-minute window-based aggregation.
- Calculating average and maximum water levels.
- Saving results in Parquet format.
- Checkpointing and recovery after restarting the streaming query.
